# 분석 도구: 잠정 가격 판단 (PER · PBR)

- 상태: 자동화 완료 (2026-11-19). **잠정**: 13~14주차(내재가치 계산)를 배운 뒤 정식 기준으로 바꾼다.
- 사용: `uv run data.py price <기업> [--peers 경쟁사1,경쟁사2]` (외부 요청 없음), 주가·주식 수를 새로 받으려면 `--fetch` (사용자 승인 후)
- 코드: `pipeline/price_level.py`, `pipeline/prices.py`, 표준 재무항목 `pipeline/standard.py`
- 성격: **숫자와 경쟁사 비교만 보여준다.** 판정 없음.

## 왜 만들었나

- **프로필:** 비싸면 적정 가격까지 기다린다(2주차 5번, 3-①). 투자할 때는 저PER 회사를 더 찾고, 고PER이면 기다린다(5-②). 비교는 경쟁사 우선(4·5·9-③). 매도는 경쟁사와 비교해 높을 때(매도-③).
- **12주차까지 배운 범위**로는 내재가치를 계산할 수 없어서, 가격 수준을 **비교**로 가늠한다 (사용자 결정).
  - 4주차: 자산가치(장부가치)와 PBR
  - 5주차: PER, 시계열·횡단면 비교
  - 11주차: 평균 회귀 (이익이 출렁이는 회사는 그해 이익만으로 싸다고 착각할 수 있음)

## 정의 (사용자 결정)

| 지표 | 정의 |
|---|---|
| PER (그해) | 보통주 주가 ÷ 그해 **기본주당순이익** (공시 값. 우선주·희석·계속영업 주당이익 제외) |
| PER (5년 평균) | 보통주 주가 ÷ 최근 5년 기본주당순이익의 평균. 이익이 출렁이는 회사용 (사용자 결정: 둘 다 보여줌) |
| PBR | 보통주 주가 ÷ 주당 장부가치. 주당 장부가치 = **지배주주 자본 ÷ 유통주식 수** |
| 시점 | **현재** + **최근 5개 회계연도 말** (12월 결산이 아닌 회사는 회계연도 말 종가) |
| 비교 | `--peers`로 고른 경쟁사의 현재 값과 나란히 (경쟁사는 분석할 때 직접 고른다) |

- 주당 기준으로 계산하므로 우선주 주가는 필요 없다.

## 조정 장부가치 (4-①, 2026-11-19 추가)

수치화되는 장부 밖 가치(수주잔고, 장부보다 비싼 부동산, 소송 금액 등)를 분석할 때 직접 적으면, '현재' 행에 **조정 전 PBR과 조정 PBR**이 나란히 나온다.

- 파일: `inputs/adjustments/<회사>.json` (회사마다 한 파일, git에 올려 기록으로 남김. 사용자 결정)
- 항목 종류는 정해 두지 않고 그때그때 적는다 (사용자 결정)
- 형식:
  ```json
  {"items": [
    {"name": "수주잔고 이익", "amount": 1200000000000, "sign": "+",
     "reason": "향후 3년 인도 예정, 과거 이익률 적용", "source": "사업보고서 2025, 접수번호 …, II.4 수주상황",
     "as_of": "2025-12-31"}
  ]}
  ```
- 금액은 재무제표와 같은 통화의 원 단위. **세금 효과는 반영하지 않고 입력한 금액 그대로** 지배주주 자본에 더하거나 뺀다 (AI가 정한 값: 세후가 필요하면 세후 금액을 입력). 주식 수는 그대로.

## 데이터

- **주가:** Yahoo Finance (`yfinance`, 사용자 결정: 자동 수집). 공식 API가 아니라 막히거나 바뀔 수 있다. 일별 시세·분할 기록·받은 시각을 `data/raw/<KR|US>/<id>/prices/` 에 그대로 보관한다.
  - 한국: 종목코드 + `.KS`(유가증권) / `.KQ`(코스닥)
  - 해외 기업(20-F)은 현지 상장 주가 (TSMC: `2330.TW`, 대만 달러. 미국 ADR `TSM`은 달러라 재무제표 통화와 달라 쓰지 않음)
- **주식 수:** 한국은 DART '주식의 총수 현황'의 유통주식 수(보통주+우선주 합계), 미국은 `CommonStockSharesOutstanding`(없으면 10-K 표지 주식 수, '범위 차이')
- **주식 분할 맞추기:** Yahoo 과거 주가는 오늘 기준으로 분할이 반영돼 있고, 공시 주당 값은 **보고서 제출일 기준**이다. 제출일 이후의 분할 비율만큼 공시 값을 맞춘다.
  - 실제 사례: Walmart는 FY2023이 끝난 뒤 3:1로 분할해 FY2023 주당순이익이 이미 분할 후 기준이었다.
  - Yahoo는 주식배당(셀트리온)·인적분할(LG)도 '분할'로 기록한다. 같은 방식으로 맞춘다.
- **검증:** 주당순이익 × 주식 수가 지배주주 순이익과 10배 넘게 어긋나면 원본 오류로 보고 제외한다 (LG화학 2016~17년 DART 원본의 주당이익이 174억·254억 원).

## 계산 안 됨 · 표시

- 주당순이익 0 이하 → 그해 이익 PER 계산 안 함. 5년 평균이 0 이하 → 평균 PER 계산 안 함
- 주당 장부가치 0 이하(자본잠식) → PBR 계산 안 함
- 주가 통화와 재무제표 통화가 다르면 계산 안 함
- '현재' 행은 **받아 둔 가장 최근 회계연도**의 이익·장부가치를 쓴다. 데이터가 오래되면(예: TSMC는 2024 회계연도까지만 있음) 현재 PER이 실제보다 높거나 낮게 나온다.
- 금융업은 업종 특성상 일반 기업과 비교하면 안 됨

## 13~14주차 이후 바꿀 부분

- 내재가치 계산(닻)과 안전마진을 더한다 (매수: 안전마진만큼 싸면, 매도-③: 내재가치를 크게 넘으면).
- 그때 이 문서의 PER·PBR은 시장의 '온도'를 재는 보조 지표로 남는다 (14주차 자료의 구조: 절대가치로 닻, 상대가치로 온도).
