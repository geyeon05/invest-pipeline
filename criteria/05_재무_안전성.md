>

  - 업종마다 적정 수준이 달라 통과선을 정하기 어렵다 (4·5주차: 비교해야 의미가 있다).
  - 자본잠식과 이자보상비율 1 미만은 업종과 무관한 사실이다.
- 근거

  - 수업: 4주차(안전성 비율), 6주차(흑자도산, 영업CF 대비 부채), 9주차(레버리지의 위험), 10주차(유동성 위험·채무상환 위험, 이자보상비율, 리만 브라더스: "아무리 멋진 스토리라도 재무제표의 바이탈 사인이 불안정하면 결코 투자해서는 안 된다")

## 1. 지표와 정의 (사용자 결정)

- **기간:** 최근 5년

| 지표 | 정의 | 묻는 것 |
|---|---|---|
| A. 부채비율 | 부채총계 ÷ **자본총계(비지배지분 포함)** | 남의 돈에 얼마나 기대나 |
| B. 유동비율 | 유동자산 ÷ 유동부채 | 1년 안에 갚을 빚을 막을 수 있나 |
| C. 당좌비율 | (유동자산 − 재고자산) ÷ 유동부채 | 재고가 안 팔려도 막을 수 있나 |
| D. 이자보상비율 | **영업이익(보고 그대로)** ÷ **이자비용(주석)** | 본업으로 이자를 낼 수 있나 |
| E. 부채 ÷ 영업CF | **부채총계** ÷ 영업CF | 본업 현금으로 빚을 몇 년에 갚나 |

**분명한 위험 (따로 표시)**
- **자본잠식:** 자본총계 ≤ 0 (완전 자본잠식)
- **이자보상비율 < 1:** 영업이익으로 이자도 못 냄. 금융업은 제외 (이자비용이 예금이자 = 영업비용)

후보였지만 빼기로 한 것:
- 알트만 Z-score: 원래 공식에 시가총액이 필요한데 주가 데이터가 없음
- 흑자도산 패턴: 기준 2의 영업CF 마이너스 표시와 겹침

## 2. 이자비용: 주석에서 읽는다 (사용자 결정)

- **한국:** 손익계산서 본문에는 "금융비용"만 있고, 이자 외에 환손실·파생상품 손실이 섞인다.
  - 예: 삼성전자 2025년 금융비용 11.7조 중 이자비용은 6,058억(약 5%)
  - 그래서 **사업보고서 XBRL 원본(DART `fnlttXbrl`)의 주석 숫자**를 읽는다. 규칙은 `pipeline/dart_xbrl.py` 맨 위에 있다.
    1. 연결 기준
    2. 금융비용 주석의 이자비용(`dart_InterestExpenseFinanceExpense`, `ReportedAmountMember`)을 우선하고, 없으면 `ifrs-full_InterestExpense`
    3. 같은 태그가 '금융상품 범주별 손익' 주석에도 다른 값(차입금 이자만)으로 나온다. 금융비용 주석 값을 쓴다 (셀트리온 2024: 756억 = 742억 + 리스 이자 14억).
    4. 합계 태그가 없으면 '상각후원가 금융부채의 이자'를 '범위 차이'로 쓴다 (현대건설 2022~23)
    5. 퇴직급여 순이자는 빚의 이자가 아니라 제외. 부호는 양수로 통일
  - **주석 XBRL은 2023년분 사업보고서(2024년 제출)부터 있다.** 2022년분까지는 본문 숫자만 있다.
    - 보고서 1건에 2년치가 있으므로 2022~2025년이 채워진다. **2021년은 빈칸** (사용자 결정. 특정 회사 분석 때 필요하면 그 회사만 사업보고서 본문에서 채운다).
    - 작은 회사는 1년 늦게 시작한다 (고영: 2024~2025만).
  - 최초 제출본에 파일이 없으면 최근 정정본을 받는다 (카카오 2023년분).
- **미국:** SEC XBRL에 이미 있다.
  - 2024년에 태그가 `InterestExpense` → `InterestExpenseNonoperating`으로 바뀌어 둘 다 찾는다.
  - Boeing은 `InterestAndDebtExpense`
  - Walmart `InterestExpenseDebt`는 차입금 이자만이라 '범위 차이', TSMC `FinanceCosts`도 '범위 차이'
  - Apple은 FY2024부터 이자비용 태그가 없어 빈칸
- **리스 이자:** 회사가 보고한 그대로 둔다. 한국(국제회계기준)은 포함, 미국은 대부분 미포함 — 조정하지 않고 표시만 (사용자 결정).
- **이자 자본화:** 공장 등 자산 원가에 넣은 이자는 빠진 값(손익계산서에 실제로 잡힌 이자)을 그대로 쓴다 (셀트리온·LG화학).

## 3. 데이터

| 항목 | 한국 | 미국 |
|---|---|---|
| 부채총계 | "부채총계" | `Liabilities`. 없으면 자산총계 − 자본총계(파생: Coca-Cola, Amazon, Walmart) |
| 자본총계 | "자본총계" (비지배지분 포함) | `StockholdersEquityIncludingPortionAttributableToNoncontrollingInterest`, 없으면 `StockholdersEquity` (비지배지분이 없는 해만 '대체', 있으면 '범위 차이') |
| 유동자산·유동부채 | "유동자산", "유동부채" | `AssetsCurrent`, `LiabilitiesCurrent` |
| 영업이익 | "영업이익", "영업이익(손실)" | `OperatingIncomeLoss` |
| 재고자산 | 기준 4와 같음 | 기준 4와 같음 |
| 영업CF | 기준 2와 같음 | 기준 2와 같음 |

- 한국 XBRL 원본은 `data/raw/KR/<고유번호>/xbrl/<접수번호>.zip` 에 그대로 보관한다.
- 새 항목으로 **자산 = 부채 + 자본 검증**이 켜졌다. 25개사 전 연도 통과 (2026-11-19).

## 4. 표시: 데이터에 있는 사실만

| 표시 | 조건 |
|---|---|
| 금융업 | 은행·보험·증권. 유동·비유동 구분이 없고 부채 대부분이 예금 등 영업부채 → 일반 기업 비율로 보면 안 됨 |
| 계산 안 함 | 자본총계 0 이하(부채비율), 재고 계정 없음(당좌비율), 이자비용 없음·0(이자보상비율), 영업CF 0 이하(부채÷영업CF) |
| 정의 일치 아님 | 기준 5가 쓰는 항목 중 대체·범위 차이·파생인 값 |
| 자산 ≠ 부채 + 자본 | 검증 실패 연도 → 매핑 확인 필요 |
