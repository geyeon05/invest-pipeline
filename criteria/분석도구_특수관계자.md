# 분석 도구: 특수관계자 거래

- 상태: 자동화 완료 (2026-11-19)
- 사용
  - `uv run data.py related <기업>`: 거래 상대 목록 (외부 요청 없음)
  - `uv run data.py related <기업> --owner 1,3,5`: 대주주 쪽으로 판단한 상대를 기록 → 그다음부터 비율 자동 계산
- 코드: `pipeline/related_party.py` (데이터는 기준 5에서 받은 사업보고서 XBRL)
- 기록 파일: `criteria/judgments/<회사>_related.json` (사용자 판단의 기록)
- 성격: 목록과 비율만 보여준다. 판정 없음. 한국 기업만.

## 왜 만들었나

- **프로필 7-④:** 대주주가 소액주주의 이익을 침해하는 구조(대리인 문제 유형 2)는 잘못된 경영방식이다. 일감 몰아주기 같은 특수관계자 거래는 **크기를 보고** 판단하고, **매출 대비**로 본다.
- **숫자 기준 3:** 정의는 **대주주 쪽**(지배회사·대주주 개인·가족 회사·기업집단 계열사) 회사로부터의 **매입 ÷ 회사 매출**. 관계기업·공동기업은 제외.
- 자동 분류 시험에서 이마트·LG화학이 0%로 나와(회사마다 거래 상대를 묶는 방식이 다름) 자동 계산을 믿기 어려웠다. 그래서 **목록을 보여주고 사용자가 직접 고르는 방식**으로 정했다 (사용자 결정 (가)).

## 보여주는 것

| 열 | 내용 |
|---|---|
| 번호 | `--owner`로 고를 때 쓰는 번호 |
| 표시 | **선택** = 기록 파일에 있는 상대 / **후보** = 회사가 최상위 지배기업·지배기업·기업집단 계열사·유의적 영향력 행사 기업·주주로 분류 / **?** = 회사가 분류를 붙이지 않음 (지배회사일 수도 있음) |
| 분류 | 회사가 XBRL에 붙인 분류를 한글로 |
| 거래 상대 | XBRL 라벨의 이름 |
| 매입·비용 / 매출·수익 / 자산 거래 | 가장 최근 연도의 금액 |

기록 파일이 있으면 **연도별 대주주 쪽 매입 ÷ 매출**이 나온다.

## 한계

- 사업보고서 XBRL 주석이 있는 **2022년 이후**만. 작은 회사는 더 늦게 시작한다 (고영: 거래 숫자 없음).
- 보고서마다 거래 상대 이름(멤버)이 달라질 수 있다. 과거 연도 비율을 보려면 목록에서 과거 연도의 같은 상대도 골라야 한다.
- '기타'로 묶인 상대는 구성을 알 수 없다.
- 거래 조건이 공정한지(시장가격인지)는 숫자로 알 수 없다. 필요하면 공시 본문의 특수관계자 주석을 읽는다 (`doc`).
- 미국 10-K는 특수관계자 거래가 구조화된 숫자로 거의 없어 지원하지 않는다.

## 시험 결과 (2026-11-19, 기록 파일은 만들지 않고 계산만 시험)

- HD현대중공업: '후보' 16곳 + '?'인 HD한국조선해양을 대주주 쪽으로 가정하면 매입 ÷ 매출이 2022년 1.12% → 2025년 5.55%
- 한국 15개사 중 '후보' 표시가 붙는 회사 9곳. 카카오·네이버·KB·이마트·NC는 후보가 없다 (회사가 계열사를 '기타 특수관계자'나 분류 없이 적음 → '?'와 목록을 보고 직접 판단).
