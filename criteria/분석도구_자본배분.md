# 분석 도구: 자본 배분 (번 돈을 어디에 썼고, 결과가 어땠나)

- 상태: 자동화 완료 (2026-11-19)
- 사용: `uv run data.py allocation <기업>` (외부 요청 없음. 주가는 `price --fetch`로 받은 것을 씀)
- 코드: `pipeline/capital_allocation.py` (주주환원 숫자는 `pipeline/returns.py`)
- 성격: **결과만 보여준다.** 판정 없음.

## 왜 만들었나

- **프로필 4-2:** 남는 현금은 **재투자하는 쪽을 더 믿고**, 근거는 재투자 뒤의 ROE·이익·현금흐름이다. 주주환원은 일시적인 주가 안정용일 수 있어 **그 자체로는 증거가 아니며**, 의도는 **회사마다 논의해서** 판단한다.
- **6주차:** FCF의 대리인 문제(제국 건설). FCF 분석의 핵심은 경영진의 **자본 배분 능력**이다.
- 그래서 기준 3(주주환원 기록)을 따로 두지 않고, 돈의 여러 쓰임 중 하나로 이 화면에 합쳤다 (사용자 결정).

## 표 (최근 5년, 사용자 결정)

| 열 | 정의 |
|---|---|
| 번 돈 | 영업CF (기준 2와 같음) |
| 설비 재투자 | 유형·무형자산 취득 − 처분 (기준 2의 순설비투자). **인수·지분 투자는 넣지 않음** (사용자 결정: 설비만) |
| FCF | 번 돈 − 설비 재투자 |
| 주주환원 | 배당 + 자사주 매입(임직원 보상 목적 제외). 계산 규칙은 `criteria/03_주주환원_기록.md` |
| FCF − 환원 | 플러스면 남음, 마이너스면 모자람 |
| 이자부 부채 증감 | 이자부 부채(차입금·사채·리스)의 전년 대비 변화. 빈칸인 회사는 차입금이 금융부채에 묶인 경우 |
| ROE | **연결 순이익 ÷ 평균 자본총계** (사용자 결정: 연결 기준) |

## ROE를 인정하나: 스프레드 (2026-11-19 추가)

- **9-②:** 빚으로 높인 ROE는 **스프레드(ROA − 이자율)가 플러스일 때만** 인정한다.
- **ROA = 영업이익 ÷ 평균 총자산** (사용자 결정: 이자를 내기 전의 이익을 이자율과 같은 선에서 비교)
- **이자율 = 이자비용 ÷ 평균 이자부 부채** (숫자 기준 7). 차입금이 금융부채에 묶인 회사는 빈칸.
- 이자율이 비정상적으로 낮거나 높은 회사(예: 현대차 금융 자회사)는 숫자를 그대로 보여주고 분석할 때 판단한다.
- 금융업은 계산하지 않는다. 재무 안전성 화면에는 스프레드가 마이너스인 해만 경고로 나온다 (사용자 결정).
- 코드: `pipeline/spread.py`

## 의도를 논의할 때 쓸 사실 다섯 가지 (사용자 결정: 모두 보여줌)

| # | 사실 | 데이터 |
|---|---|---|
| ① | 환원이 몇 년 이어졌나 (배당·자사주 매입 각각) | 위 표 |
| ② | 환원이 FCF보다 큰 해, 그해 이자부 부채 증감 | 위 표 |
| ③ | 자사주: 취득·소각·처분·연말 보유 주식 수 | 한국: DART 자기주식 현황·주식 총수 현황. 미국: 소각 태그가 있는 회사만 |
| ④ | 매입 시점의 주가 흐름 | 한국: **매입 결정 전 6개월** 주가 변화 (기준 1의 자사주 취득결정 공시 날짜 기준, 보상 목적이면 표시). 미국: 매입이 있던 **회계연도 1년** 주가 변화 (매입 날짜가 연 단위로만 공시됨) |
| ⑤ | 발표한 환원 정책을 지켰나 | 기준 1 결과 중 **환원 약속만**: 한국은 자사주 취득 약속, 미국은 10-K 배당 의도 문장 |

- ④의 6개월·1년은 AI가 정한 값이다. 사용자가 바꿀 수 있다.
- ⑤의 '판정 불가'는 기준 1의 규칙(현 대표이사의 판정 끝난 약속이 3건 미만) 때문이다.

## 한계

- 인수·지분 투자를 넣지 않으므로, 인수가 많은 회사는 '쓴 돈'이 작게 보인다.
- '재투자 뒤 ROE가 나아졌나'는 같은 표의 ROE 추세로 본다. 재투자 직후(결과가 나오기 전)의 믿음은 **분석할 때 판단**한다 (숫자 기준 8).
- 금융업은 영업CF·설비투자의 의미가 달라 FCF 비교는 참고만.
