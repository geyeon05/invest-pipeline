# 분석 도구: 현금 창출

> **2026-11-19 변경:** 투자기준이 아니라 **분석 도구**로 바꿨다 (판정 없이 결과만 보여주므로). 전체 구조는 `criteria/README.md`.
>
> **이 도구를 쓰는 내 기준**
> - **영업CF가 꾸준히 늘었나 (프로필 6-①, 숫자 기준 2):** 최근 5년(전년 대비 5번) 중 **3번 이상 증가** + **5년 연평균 증가율 0% 초과**면 충족.
>   감소한 해는 따로 표시하고, **영업CF가 마이너스인 해는 경고**(이유 확인). 처음·마지막 해가 0 이하라 연평균을 못 구하거나 비교할 해가 5번이 안 되면 '판단 불가'.
>   성장기 회사는 주주환원 대신 이 기록으로 인정한다 (프로필 4-1 수정).
> - 매도-②: 회사가 바뀌었는지 볼 때 영업CF를 최근 5년 규모와 비교한다.

- 상태: **규칙 확정, 자동화 완료** (2026-11-18)
- 사용: `uv run data.py cashflow <기업> [--source]` (`pipeline/cashflow.py`). 외부 요청 없음
- 성격: **결과만 보여준다.** 통과선·판정·판단 기록을 두지 않고, 회사마다 맥락을 보고 사용자가 판단한다 (사용자 결정)
- 근거
  - 투자자 프로필 (`investor_profile.md`) 4번: 둘 다 보지만 **이미 돈을 버는 회사**에 더 큰 비중
  - 투자자 프로필 1번: 증명된 것(실제 숫자)만 믿는다
  - 2주차 자료: "자산은 내 주머니에 돈을 가져다주는 것", "돈이 돈을 버는 시스템", 수익성 분석(비용-효익)
- 질문: **이 회사는 실제로 현금을 꾸준히 벌어들이는가?**

## 1. 지표

| 지표 | 계산 | 보여주는 것 |
|---|---|---|
| A. 영업현금흐름 | 현금흐름표의 영업활동 현금흐름 | 본업으로 실제 현금이 들어왔는가 |
| B. 잉여현금흐름 (FCF) | 영업현금흐름 − 순설비투자 | 사업을 유지하는 데 쓰고 남은 현금 |
| C. 이익의 현금 전환 | 영업현금흐름 ÷ 연결 순이익 | 장부상 이익이 진짜 현금으로 들어오는가 |

## 2. 기간과 판단 방식

- **최근 5년**, 해마다 확인한다.
- 통과선(5년 중 몇 년, 몇 %)은 **정하지 않는다.** 반도체 불황기의 대규모 투자처럼 FCF가 마이너스인 이유는 회사마다 달라서, 맥락을 보고 그때그때 판단한다 (사용자 결정).
- 화면에는 참고용으로 "5년 중 몇 년"(영업CF > 0, FCF > 0, 전환율 ≥ 1.0)을 보여준다. 통과선이 아니다.

## 3. 표준 재무항목 정의 (`pipeline/standard.py`)

| 항목 | 정의 | 결정 |
|---|---|---|
| 영업현금흐름 | 회사가 보고한 값 **그대로** | 국제회계기준(IFRS)은 리스 원금 상환을 재무활동에, 이자 지급을 영업·재무 중 선택해 적을 수 있어 미국 기준보다 크게 나올 수 있다. **조정하지 않고 표시만** 한다 |
| 순설비투자 | (유형자산 취득 + 무형자산 취득) − (유형자산 처분 + 무형자산 처분) | 무형자산 포함: IFRS 기업은 개발비를 무형자산으로 잡아 투자활동으로 나가고, 미국 기업은 연구개발비가 영업현금흐름에서 이미 빠지므로 차이를 줄이기 위함. 처분도 빼서 순액으로 본다 |
| 연결 순이익 | 비지배지분 포함 | 영업현금흐름(회사 전체)과 범위를 맞춤. 미국 기업은 비지배지분이 없는 해에만 지배주주 순이익(`NetIncomeLoss`)으로 대체하고 "대체(조건 확인)"으로 표시 |

- 지출·처분 금액은 회사마다 부호가 달라 **양수로 통일**한다 (`+abs` 표시).
- 미국 `PaymentsToAcquireProductiveAssets`(Amazon, NVIDIA)는 유형자산 외 생산용 자산이 섞일 수 있어 "범위 차이 가능"으로 표시한다.

## 4. 계산 규칙 (구현 사항)

- 무형자산 취득·유형자산 처분·무형자산 처분 계정이 없으면 **0으로 계산**하고 표시한다. 미국 기업은 대부분 무형자산 취득 계정이 없다 (연구개발비를 비용 처리하므로 예상된 결과). 유형자산 취득 계정이 없으면 순설비투자와 FCF를 계산하지 않는다.
- 순이익이 0 이하인 해는 현금 전환율을 계산하지 않는다.

## 5. 표시: 데이터에 있는 사실만

기준 숫자나 해석이 들어간 표시는 두지 않는다 (사용자 결정 2026-11-18). 맥락 판단은 사용자가 한다.

| 표시 | 조건 |
|---|---|
| 순이익 적자 | 순이익 ≤ 0 → 전환율 계산 안 함 |
| 계정 없음 → 0으로 계산 | 무형자산 취득·유형자산 처분·무형자산 처분 계정이 없는 해 |
| 유형자산 취득 계정 없음 | 순설비투자·FCF 계산 안 함 |
| 정의 일치 아님 | 대체 태그·범위 차이 가능 항목 |
| 금융업 | 영업현금흐름에 예금·대출이 들어가고 설비투자 개념이 달라 지표의 의미가 다름 |
| 데이터 공백 | 연차보고서는 나왔지만 재무 데이터(XBRL)에 그해 값이 없음 (예: TSMC FY2025) |
| IFRS | 영업현금흐름이 미국 기준보다 크게 나올 수 있음 (조정하지 않음) |

- 처음에는 해석이 들어간 표시도 만들었으나 사용자 결정으로 뺐다: 전환율 3배 초과, 처분이 취득의 20% 이상, "흑자인데 영업CF 마이너스 → 금융 자회사 등 확인", FCF 마이너스의 원인 후보(전년 대비 30% 변화). 기준 숫자를 AI가 정했고 해석이 들어가기 때문이다.
