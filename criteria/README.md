# 투자기준과 분석 도구: 전체 지도

- 갱신: 2026-11-19
- 출발점: `investor_profile.md` (2주차·3~12주차·매도·보유 문답). **기준은 문답에서 내가 답한 것에서만 나온다.**
- 수업 요약: `criteria/수업요약_3-12주차.md`

## 1. 투자기준 (규칙)

| 기준 | 규칙 | 근거 (프로필) | 도구 |
|---|---|---|---|
| **경영진의 약속 이행** | 약속 3건 이상 판정됐을 때 현 대표이사 불이행 0건 통과, 1건 주의, 2건 이상 탈락. 이전 대표이사 시절 불이행이 있으면 한 단계 낮춤. **유일하게 '탈락'이 있는 기준** (숫자 기준 10: 유지) | 1, 1-1, 3 | `promises` · `criteria/01_경영진_약속이행.md` |
| **영업CF가 꾸준히 늘었나** | 5번 중 3번 이상 증가 + 5년 연평균 0% 초과. 감소한 해 표시, 마이너스인 해는 경고. 성장기 회사의 증거 | 4-1, 6-① (숫자 기준 2) | `cashflow` |
| **스프레드** | 스프레드 = ROA(영업이익 ÷ 평균 총자산) − 이자율(이자비용 ÷ 평균 이자부 부채). 빚으로 높인 ROE는 스프레드가 플러스일 때만 인정 | 9-② (숫자 기준 7) | 숫자는 `allocation`(ROE 옆), 마이너스인 해는 `safety`에 경고 |
| **경고 신호** | 자본잠식·이자보상비율 1 미만·이익조정 신호·영업CF 마이너스·빅 배스는 **탈락이 아니라 경고**. 원인을 확인한다 | 6-①, 10-③, 12-①·② | `safety`, `quality`, `cashflow` |
| **매도** | 회사가 바뀌었을 때(경쟁사 대비 숫자 악화, 영업CF가 최근 5년 규모에서 벗어남 + 정성적 이유)와 가격이 너무 올랐을 때(내재가치를 크게 넘거나 경쟁사보다 높을 때) **나눠서** 판다. 더 좋은 기회만으로는 팔지 않는다 | 매도-①~③ | `cashflow`, `price` |
| **보유 중 점검** | 사업보고서로 연 1번 + 뉴스·시장 흐름. 대표이사 변경·대규모 자금조달·소송·제재·중대재해·대주주 지분 변동은 바로 확인 | 보유-① | `filings` |

## 4. AI가 정한 값 (사용자 확인: 2026-11-19, 그대로 둠)

기준과 정의는 사용자가 정했고, 아래는 그것을 구현하면서 **AI가 정한 세부 값**이다. 바꾸려면 해당 코드의 값을 고친다.

| 도구 | 값 | 왜 | 코드 |
|---|---|---|---|
| 자본 배분 ④ | 매입 시점의 주가 흐름: 한국은 **매입 결정 공시 전 6개월**, 미국은 **매입한 회계연도 1년** | "떨어진 뒤에만 매입했나"를 볼 길이. 미국은 매입 날짜가 연 단위로만 공시됨 | `capital_allocation.LOOKBACK_DAYS` |
| 가격 판단 | 주당순이익 × 주식 수가 지배주주 순이익과 **10배 넘게** 어긋나면 그해 주당순이익 제외 | 단위 오류(LG화학 2016~17)만 잡고 주식 수의 정상 변동은 두려고 | `price_level.analyze` |
| 가격 판단 | '연말' 주가 = **회계연도 말** 종가 (Apple 9월, Microsoft 6월, NVIDIA·Walmart 1월) | 그해 이익과 시점을 맞추려고 | `price_level.analyze` |
| 가격 판단 | 주당 장부가치의 주식 수 = **보통주 + 우선주 유통주식** (DART 합계 행) | 지배주주 자본은 보통주·우선주 주주 모두의 몫 | `price_level.analyze` |
| 가격 판단 | 미국 주식 수 태그가 없으면 **10-K 표지 주식 수** ('범위 차이', 제출일 무렵 기준) | Coca-Cola·Walmart가 재무상태표 태그를 안 씀 | `standard.US_TAG_RULES` |
| 가격 판단 | '현재' 행 = 받아 둔 **가장 최근 회계연도**의 이익·장부가치 (분기 실적 안 씀) | | `price_level.analyze` |
| 재무 안전성 | 금융비용 주석 = XBRL의 **`ReportedAmountMember`** 값 ("금융비용 주석 우선"은 사용자 결정, 알아보는 방법은 AI) | 셀트리온 2024 756억(리스 포함) vs 742억(차입금만)에서 확인 | `dart_xbrl._parse` |
| 재무 안전성 | 이자비용 두 태그가 **1% 넘게** 다르면 '범위 차이' 표시 | 반올림 차이는 무시 | `dart_xbrl.interest_expense` |
| 스프레드 | 한국 이자부 부채 = 단기·장기차입금, 유동성장기부채, 사채, 리스부채, 전환·교환·신주인수권부사채, 기업어음 (조정 줄 제외) | 이자가 붙는 빚을 모두 | `standard.KR_DEBT_RX` |
| 스프레드 | 미국 이자부 부채 = 장기차입금(유동분 포함) + 기업어음·단기차입금 + 금융리스, **운용리스 제외** | 미국 이자비용에 운용리스 이자가 안 들어가므로 분자·분모를 맞춤 | `standard.US_DEBT` |
| 스프레드 | 차입금·사채 줄이 없고 '금융부채' 줄이 있으면 **묶였다고 보고 빈칸** (빈칸은 사용자 결정, 판단 조건은 AI). 정말 빚이 없는 회사도 빈칸이 될 수 있음 (고영 2025) | | `standard._kr` |
| 이익의 질 E | 대표이사 = 직위에 '대표' 또는 담당업무에 '대표이사'·'각자대표'·'공동대표'·'대표집행임원'·'CEO' ('계열사대표이사후보추천위원' 제외) | 회사마다 적는 칸이 다름 (현대차 직위 '사장' + 업무 '대표이사') | `dart_officers.CEO_JOB` |
| 이익의 질 E | 전년 명단에 없던 이름이 **한 명이라도** 생기면 대표이사 교체 | 각자대표 체제에서 한 명만 바뀌어도 새 경영진 | `earnings_quality.analyze` |
| 이익의 질 E | 대표 여부가 적히지 않은 해('경영총괄' 등)는 '확인 불가' | 추측하지 않음 | `dart_officers.ceos` |
| 공통 | 업종 코드가 금융업(64~66)이어도 **재무상태표에 유동자산 줄이 있으면 금융업 아님** | LG(지주)와 KB금융지주가 같은 지주회사 코드 | `standard.is_financial` |
| 현금 창출 | 처음·마지막 해 영업CF가 0 이하라 연평균을 못 구하면 '판단 불가' (숫자 기준은 사용자 결정) | 계산이 안 되는 경우의 처리 | `cashflow.analyze` |

| 특수관계자 | '후보' = 회사가 최상위 지배기업·지배기업·기업집단 계열사·유의적 영향력 행사 기업·주주로 분류한 상대. '?' = 분류를 붙이지 않은 상대 (지배회사일 수도 있음, 예: HD현대중공업의 HD한국조선해양) | 확정은 사용자 | `related_party.OWNER_HINT` |

| 뉴스 (`news`) | 검색어 트렌드: **최근 1년 주 단위 + 최근 30일 일 단위**를 받고, 최근 4주·1년 평균·1년 최대 주·최근 7일을 표시. 받은 날 기준 아직 끝나지 않은 주는 값이 낮게 나오므로 평균·최대에서 빼고 '진행 중'으로 따로 표시. 값은 기간 안 최대 = 100인 상대값이라 1년을 함께 봐야 '평소보다 높은지' 알 수 있음. 한국 회사만 | 분위기(나)를 기사 수 대신 검색량으로 보기로 한 것은 사용자 결정 | `news.fetch_trend` |
| 뉴스 줄이기 (`news.events_of`) | 광고·홍보성 낱말 (`news.AD`): [광고]·협찬 표시, 할인·경품·쿠폰·이벤트, 리딩방, 출시·사전예약·캠페인·수상·기념·행사·신제품 등. '공개'·'페스티벌'은 뺌(실적 공개·논란 기사가 걸려서), '[단독]'은 걸려도 남김 | 광고 범위 (b), 예외 (a)는 사용자 결정 | `news.AD`, `news.KEEP` |
| 뉴스 줄이기 | 같은 사건: 제목 낱말 **35%** 이상 겹치고 **2일** 안 (중간) **또는** 같은 날 '고유한 낱말'이 **2개** 이상 겹침. 고유한 낱말 = 그 묶음 전체 제목의 **10% 이하**에만 나오는 낱말 (회사 이름·검색어는 뺌). 낱말 끝 조사(은·는·이·가·을·를·의·에·으로 등)는 떼고 비교 | 묶는 방식(중간 + 고유 낱말)은 사용자 결정, 숫자는 AI | `news.SAME_EVENT`, `DISTINCT_SHARE`, `DISTINCT_MIN` |
| 뉴스 줄이기 | **2곳 이상** 언론사가 다룬 사건만 ((가) 사건, (다) 산업·경쟁). '[단독]' 기사는 1곳이어도 남김. (나) 분위기·시황은 이 규칙 없이 묶기만. 언론사는 **주소의 등록 도메인**으로 셈 (news.hankyung.com = hankyung.com; Google은 언론사 주소 사용) | 2곳·시황 예외·[단독] 예외는 사용자 결정, 도메인 통일 방식은 AI | `news.MIN_SOURCES`, `news._outlet` |
| 거시 지표 (`macro`) | 지표 5개: 한국 기준금리(ECOS 722Y001), 원/달러 환율(ECOS 731Y001), 미국 실효 연방기금금리(FRED FEDFUNDS), 미국 10년 국채 금리(FRED DGS10), WTI 유가(FRED DCOILWTICO). 기간 5년. 최근 값·1년 전·5년 범위만 표시 | '금리·환율·유가'(7주차)는 사용자 결정, 구체적인 지표와 코드는 AI | `macro.SERIES` |
