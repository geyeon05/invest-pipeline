# 분석 도구: 주주환원 상세 (자본 배분의 상세 화면)

> **2026-11-19 변경:** 투자기준이 아니라 **분석 도구**로 바꾸고, **자본 배분 도구로 합쳤다** (`criteria/분석도구_자본배분.md`).
> 프로필 4-2: 주주환원은 일시적인 주가 안정용일 수 있어 **그 자체로는 증거가 아니며**, 의도는 **회사마다 논의해서** 판단한다.
> 이 문서는 자본 배분 화면의 '주주환원' 숫자가 어떻게 계산되는지(보상 목적 매입 차감, 소각 등)를 적은 **상세 규칙**으로 남긴다.
> 명령: 요약은 `data.py allocation <기업>`, 자세한 내역은 `data.py returns <기업>`.

- 상태: **규칙 확정, 자동화 완료** (2026-11-18)
- 사용: `uv run data.py returns <기업> [--source]` (외부 요청 없음), 한국 기업 주식 수 데이터는 `--fetch` (사용자 승인 후 DART 요청)
- 코드: `pipeline/returns.py`, `pipeline/dart_shares.py`, 표준 재무항목 `pipeline/standard.py`
- 성격: **결과만 보여준다.** 통과선·판정 없음. 표시는 데이터에 있는 사실만 (기준 2와 같은 원칙)
- 근거
  - 투자자 프로필 (`investor_profile.md`) 4-1번: 주주에게 돌려주는 행동은 경영진을 믿을 수 있는 **"행동으로 된 증거"**
  - 2주차 자료: 자본 시스템(돈이 돈을 버는 구조), 정보 비대칭(말보다 행동)
- 기준 1과의 차이: 기준 1은 "약속한 것을 지켰는가", 기준 3은 "약속과 상관없이 실제로 얼마나, 얼마나 꾸준히 돌려줬는가"

## 1. 지표와 기간

- **기간:** 최근 5년, 해마다 표시

| 지표 | 정의 (사용자 결정) |
|---|---|
| A. 배당 지급액 | **지배기업이 자기 주주에게 지급한 배당만.** 현금흐름표 값을 쓴다. 소수주주 배당이 별도 줄로 있으면 "배당금 지급" 줄을 지배기업 몫으로 보고 소수주주 배당은 따로 표시, 한 줄뿐이면 "구분 불가"로 표시 |
| B. 자사주 매입액 | 현금흐름표의 자사주 매입에서 **임직원 보상 목적 매입을 뺀 값** |
| C. 자사주 소각 | 소각한 주식 수 |
| D. 환원 비율 | (A + B) ÷ **지배주주 순이익**. 지배주주 순이익이 0 이하인 해는 계산하지 않음 |
| E. 주식 수 변화 | **발행주식 총수와 유통주식 수 둘 다** (발행주식은 소각해야 줄고, 유통주식은 사기만 해도 줄며 임직원에게 다시 나가면 늘어남) |

## 2. 데이터

| 지표 | 한국 | 미국 |
|---|---|---|
| A | 현금흐름표 "배당금(의) 지급" | `PaymentsOfDividendsCommonStock`, 없으면 `PaymentsOfDividends`(비지배지분 없는 해만 대체, 그 외 범위 차이 가능) |
| B | 현금흐름표 "자기주식(의) 취득" − 보상 목적 매입 (3장) | `PaymentsForRepurchaseOfCommonStock`. 임직원 보상의 세금 원천징수용 매입은 별도 태그라 들어가지 않음 |
| C | DART API "자기주식 취득 및 처분 현황"(tesstkAcqsDspsSttus)의 소각 수량 | `StockRepurchasedAndRetiredDuringPeriodShares`, `TreasuryStockSharesRetired` |
| D | 손익계산서 "지배기업의 소유주에게 귀속되는 당기순이익" | `NetIncomeLoss` |
| E | DART API "주식의 총수 현황"(stockTotqySttus)의 발행주식 총수·유통주식 수 | `CommonStockSharesIssued`, `CommonStockSharesOutstanding` |

- 한국 C·E의 DART 응답은 `data/raw/KR/<고유번호>/shares/` 에 그대로 보관한다.
- 미국 기업 일부는 XBRL에 주식 수가 없는 해가 있다 (예: Microsoft 발행주식 FY2024 이전, 소각 수량). 비워 두고 채우지 않는다.

## 3. 보상 목적 자사주 매입 빼기 (한국, 사용자 결정)

1. 기준 1에서 받은 **자기주식 취득결정 공시**(신탁은 계약 체결결정)의 취득목적(계약목적)을 읽는다.
2. 보상 목적인지 판단한다.
   - 본문에 "약 N억원은 … 주식기준보상 … 목적" 같은 **금액 문장**이 있으면 그 금액 비율로 나눈다 (예: 현대차 2024-11 "약 7,000억원은 주주가치 제고, 약 3,000억원은 주식기준보상" → 30%, 삼성전자 2025-07 "1조 1,000억원은 … 주식기준보상" → 1.1조 ÷ 3.9119조).
   - 금액 문장이 없고 목적이 보상뿐이면 전부 (예: "임직원 주식보상", "우리사주조합에 자기주식 출연").
   - 목적이 섞였는데 금액을 나눌 수 없으면 **"목적 혼합"으로 표시하고 빼지 않는다.**
3. 그 프로그램의 **결과보고서 일별(신탁은 월별) 취득 내역**을 연도별로 합산하고, 보상 비율을 곱해 그 해 현금흐름표 매입액에서 뺀다.
   - 결과보고서의 날짜 형식(`2026년 01월 30일`, `2020.10.27`, `2018/04/30`)과 주식 종류(`보통주식`, `기명식2우선주` 등)는 회사·연도마다 다르며 한 공시 안에서도 섞인다. 삼성전자·현대차·KB금융의 결과보고서 31건 모두 연도별 합계가 보고된 총액과 일치함을 확인했다.
   - 결과보고서 기준 보상 매입액이 현금흐름표 매입액보다 크면 0으로 처리하고 표시한다 (결제 시점 차이 등).

## 4. 표시: 데이터에 있는 사실만

| 표시 | 조건 |
|---|---|
| 소수주주 몫 구분 불가 | 현금흐름표에 소수주주 배당이 별도 줄로 없음 |
| 소수주주 배당 별도 | 별도 줄이 있으면 금액 표시 (환원에 넣지 않음) |
| 계정 없음 | 배당 또는 자사주 매입 계정이 없는 해 (없었거나 계정을 찾지 못함) |
| 보상 목적 매입 차감 | 차감한 금액과 근거 공시 (취득결정 접수번호, 목적, 비율의 근거) |
| 목적 혼합 | 보상 목적 금액을 나눌 수 없어 차감하지 않음 |
| 지배주주 순이익 적자 | 환원 비율 계산 안 함 |
| 자기주식 처분 수량 | DART 자기주식 현황의 처분 수량 (용도는 해석하지 않음) |
| 정의 일치 아님 | 기준 3이 쓰는 항목 중 대체 태그·범위 차이 가능 항목 |
| 데이터 미수집 | DART 주식 수 데이터나 취득결정 본문을 아직 받지 않음 |
